# Xray-Side P0-5/6/7 Blockers Closed

Date: 2026-08-06

## Summary
Closed the three outstanding Xray-side blocker classes for RC.2
re-eligibility: script-update safety (P0-5), atomic mode switching
(P0-6) and real-path observation (P0-7).

## P0-5: update_sh / alternate self-update candidate guard
- `tools/apply_to_repo.py` now rewrites every `download_script_file`
  call in `install.sh` so updates download to
  `install.sh.rxa-candidate.$$`, run `bash -n` + schema/menu/CLI/hook
  validation (`rxa_candidate_guard`), and only then `mv` the candidate
  over the running script. Any failure keeps the old version.
- Two update paths were covered: `update_sh()` and the alternate
  self-update entry used by the update menu item.
- The guard is re-applied on every apply and enforced by the strengthened
  `.github/test/test_rill_xray_agent.sh` grep set.

## P0-6: four-party mode transaction
- `rxa_apply_mode` is now a transaction: Runtime WAL (config+runtime)
  → systemd units → live observation snapshot → persist config.
  Every party is verified; any failure rolls back Runtime, units and
  config to the previous mode. `NO_SYSTEMD` contexts skip only the
  unit-state verification loop.
- Backed by `tests/test_mode_transaction.py` (success, safe-disabled,
  already-in-mode, runtime rejection rollback, observe-failure rollback,
  invalid mode).

## P0-7: observe the real host layout
- The observer root moved from the agent-owned mirror directory to the
  real host layout used by the Xray installer (`/etc/<host>`, where
  `<host>` is the installer identity): observe.py default,
  `rill-xray-agent-xray-observe.service` `RILL_XRAY_HOST_ROOT` and
  `rill-xray-agent-xray-observe.path` `PathChanged` all point at the real
  Xray configuration. Rill core/payload never carry the host identity.
- Backed by `tests/test_observer_real_paths.py`.
- Identity boundary: `scripts/verify_package_tree.py` and
  `tests/test_package_identity.py` now except
  `integrations/xray_bash_onekey/` from the host-token scan, per the
  documented policy.

## Verification
